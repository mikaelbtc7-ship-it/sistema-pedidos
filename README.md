# Sistema de Pedidos

Controle de pedidos, financeiro e envio para as empresas
**KYMEX 3D**, **ROSA DOS VENTOS** e **CASAÊ 3D**.

**Site:** https://mikaelbtc7-ship-it.github.io/sistema-pedidos/

Página única, sem servidor. Os dados ficam no navegador e, quando a
sincronização está configurada, também numa conta Firebase de vocês.

## Recursos

- **Colar do WhatsApp** — cola a conversa e o sistema preenche o pedido sozinho
- **Pedidos** por empresa, com status, pagamento e busca
- **Financeiro** — entradas automáticas dos pedidos + despesas manuais
- **Envio** — endereço com busca por CEP, etiqueta 10×15 para imprimir,
  "Copiar p/ Melhor Envio" e exportação em CSV
- **Backup** — exportar/importar tudo em um arquivo `.json`

## Sincronizar entre celular e computador

Veja **[COMO-CONFIGURAR.md](COMO-CONFIGURAR.md)**.
Sem essa configuração, cada aparelho tem a própria lista.

## Rodar sem internet

Basta abrir o `index.html` no navegador. Nesse modo não há login nem
sincronização — funciona só naquele aparelho.
