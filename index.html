Como funciona

Este sistema não emite a etiqueta oficial (com rastreio e frete pago) — isso só o Melhor Envio faz. Aqui você: (1) imprime uma etiqueta de endereço para colar na caixa, e (2) copia os dados de cada envio para colar rápido ao adicionar o envio no painel do Melhor Envio. Preencha o endereço na aba Pedidos, dentro de cada pedido.
